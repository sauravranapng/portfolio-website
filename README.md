# Saurav Rana — Portfolio

A responsive personal portfolio built with React and Vite. The UI is split into reusable React components, with experience, project highlights, skills, and recognition stored as data in `src/App.jsx`.

## Requirements

- Node.js 20.19+ or 22.12+
- npm

## Develop

```sh
npm install
npm run dev
```

## Production build

```sh
npm run build
npm run preview
```

The production site is generated in `dist/`. Google Fonts load when online; system font fallbacks are included.
